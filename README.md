# Developer Portfolio

Professional portfolio website for Jomar Vallite showcasing Shopify, e-commerce systems and API integrations.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this repository at https://vercel.com/new and choose the Next.js framework. Vercel will build it automatically.

## Before sharing

Check public project descriptions for client confidentiality. Replace any placeholder contact links with your own.
