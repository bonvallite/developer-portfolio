# Portfolio publication checklist
- Review notebook outputs, scripts and fixtures for identifying data, health measurements, secrets or employer records.
- Replace source data with synthetic examples.
- Document Python versions, dependencies, CLI inputs and outputs.
- Test valid headers, extra title rows, mixed columns and malformed files.
- Do not describe prompt truncation as retrieval-augmented generation.
- Publish a verified GitHub repository path and verify Vercel deployment separately.
